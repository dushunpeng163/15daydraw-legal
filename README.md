## Why a separate repo?

The main app repository is private. GitHub Pages on the free plan requires the source repo to be public, so the legal pages are extracted here. The main repo's `Assets/Resources/compliance/{privacy_policy_url,tos_url}.txt` point to URLs hosted here.

## How to update

1. Edit the `.html` file
2. Bump the "Last Updated" date at the top
3. `git commit && git push` — GitHub Pages auto-rebuilds within 1-2 minutes
